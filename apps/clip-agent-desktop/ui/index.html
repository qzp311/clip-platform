本地素材入口

选择本地视频（单集/多集）用于本地测试或临时素材；云端剧包请在管理台创建任务

云端剧包标准流程

  • 1. TOS 签名地址下载 ZIP首次执行
  • 2. 解压并按集号扫描视频首次执行
  • 3. 分集 ASR 与跨集混剪每次任务执行
  • 4. 成片上传 TOS按配置执行
  • 5. ZIP 和分集缓存本地保留

用户可手动打开缓存目录进行管理。只要缓存文件仍在本机，重跑或后续混剪会直接复用，不重复下载。
