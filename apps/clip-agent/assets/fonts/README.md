# 可商用字体目录

本目录存放渲染花字、字幕、角标时使用的字体文件。

## 字体清单

| 字体 | 文件名 | 授权 | 说明 |
|---|---|---|---|
| 抖音美好体 | `DouyinSansBold.ttf` | OFL-1.1 | 默认回退字体，抖音与方正字库联合开发 |
| 站酷高端黑体 | `ZCOOLGaoDuanHei-Regular.ttf` | 免费商用 | 粗黑醒目，适合标题 |
| 阿里巴巴普惠体 | `Alibaba-PuHuiTi-Regular.ttf` | 阿里免费商用 | 现代通用 |

## 下载地址

请从官方渠道下载字体文件，替换本目录下的同名文件：

- 抖音美好体：https://www.douyin.com/font/
- 站酷高端黑体：https://www.zcool.com.cn/special/zcoolfonts/
- 阿里巴巴普惠体：https://fonts.alibabadesign.com/

## 注意事项

- 请勿随意添加未确认授权的字体文件。
- 字体授权协议请保留在法务/运营处备查。
